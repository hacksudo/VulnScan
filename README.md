# 🛡️ Hacksudo VulnScan 

A powerful, containerized Web Vulnerability Scanner featuring industry-standard security tools (Nmap, Nikto, SSLScan, TestSSL). Fully packaged into a self-contained Docker deployment that sets up in seconds.

## 📦 Quick Install via Release (Recommended)

To make deployment as easy as possible, the entire application (including the pre-built Docker image and the massive pre-seeded database) has been packaged into a single ZIP file available in the **Releases** section. 

You **do not** need to build the Docker image from source!

### Step 1: Download the Release
1. Navigate to the **[Releases](https://github.com/hacksudo/VulnScan/releases)** page on this repository.
2. Download the latest `Hacksudo-Vuln-Scan.zip` asset attached to the latest release.

### Step 2: Extract & Deploy
1. Unzip the downloaded file:
   ```bash
   unzip Hacksudo-Vuln-Scan.zip
   cd Hacksudo-Vuln-Scan
